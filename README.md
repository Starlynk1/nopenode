# Nope Node

---

Are you tired of looking at your minimap and not knowing if that flower can be picked? Not sure you
are skilled enough to get a wee bit of ore?

Well search no more! Nope Node will make your life as a gatherer much simpler.

Mouse over a node on the minimap and like a tinkerers dream, the node is recolored. But don't worry,
quest text on the same tooltip is left alone.

## Colors

Your skill is your current rank plus any bonus. The node's required skill is the point where it
turns orange and can be gathered.

| Color  | Is it Nope or Run for it!                                                      |
| ------ | ------------------------------------------------------------------------------ |
| Red    | Nope! You cannot gather it                                                     |
| Orange | Gather that thing! Always get a skill point                                    |
| Yellow | Keep on gathering! But don't fret when you don't skill up, it happens          |
| Green  | Up to you and your needs, odds are you're only getting mats and no skill point |
| Gray   | No skill points, but free coin can be had!                                     |

## Install

Install it with the CurseForge app, or copy the `NopeNode` folder into
`World of Warcraft/_classic_beta_/Interface/AddOns`. The folder name must stay `NopeNode`.
